# 기능 개발

공통 기준은 프로젝트 `AGENTS.md`를 따른다. 해당 작업에 연결된 참고 지침만 읽고, 위임할 때 필요한 문서 경로를 전달한다. 필요한 단계만 위임하며 단순한 변경은 직접 처리한다.

- 설계 판단이 필요하면 `architect`에 요구사항과 기존 구조를 전달한다.
- 합의된 설계를 `implementer`에 담당 파일과 함께 전달한다.
- 구현 후 `verifier`에 요구사항, 실제 변경 범위, 실행한 검증과 미확인 사항을 전달한다.

설계에 의존하는 구현과 구현에 대한 검증은 앞 단계 결과를 받은 뒤 진행한다. 독립 작업만 병렬화한다.
주 에이전트는 결과를 통합하고 실제 코드와 대조하여 필요한 보완을 수행한다.
에이전트를 사용할 수 없으면 직접 처리하고 독립 검증을 수행하지 못한 사실을 보고한다.
