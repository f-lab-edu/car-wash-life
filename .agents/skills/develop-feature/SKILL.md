# 기능 개발

프로젝트 AGENTS.md, 관련 코드 및 사용자와 합의한 요구사항을 확인한다. 필요한 단계만 위임하고, 단순한 변경은 주 에이전트가 직접 처리한다.

## 역할과 위임

- `architect`: 설계 판단이 필요할 때 기존 구조, 요구사항 및 미정 사항을 전달해 변경 구조와 구현 순서를 제안하게 한다.
- `implementer`: 코드 작업이 허용되었을 때 요구사항, 선택한 설계 및 담당 파일을 명시해 구현을 위임한다. 같은 코드베이스에서 다른 작업이 진행될 수 있고 다른 사람의 변경을 되돌리지 않아야 한다고 알린다.
- `verifier`: 구현 결과의 변경 범위, 요구사항 및 기존 검증 결과를 전달해 독립적인 검토와 관련 테스트 실행을 위임한다. 소스·테스트·설정 수정과 커밋은 맡기지 않는다.

설계만 요청받았다면 설계 결과를 전달하고 구현으로 넘어가지 않는다. 설계에 의존하는 구현과 구현 결과에 대한 검증은 앞 단계 결과를 받은 뒤 진행한다. 독립적인 작업만 병렬로 위임하고 수정 담당 파일이 겹치지 않게 한다.

## 통합과 완료

주 에이전트가 결과를 통합하고 리뷰 지적을 요구사항과 코드에 대조한다. 수정이 필요한 문제는 허용된 범위에서 직접 처리하거나 구현 에이전트에 다시 맡기고, 변경한 동작에 관련된 검증을 실행한다.

프로젝트 AGENTS.md의 검증과 커밋 기준을 따른다. 결과에는 변경한 동작, 검증 결과 및 남은 문제를 포함한다. 사용한 에이전트를 사용할 수 없다면 제한을 알리고 해당 단계를 직접 수행하며, 수행하지 않은 독립 검증을 했다고 보고하지 않는다.
