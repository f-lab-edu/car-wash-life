## 인증 기능 불변조건

- 회원가입 시 이메일과 비밀번호는 필수이고, 비밀번호 원문은 저장하지 않는다.
- 이메일 인증은 현재 범위에서 인증 완료 상태로 저장한다.
- 로그인 실패 응답으로 이메일 존재 여부나 계정 정보를 노출하지 않는다.
- AccessToken의 유효기간은 24시간이며 RefreshToken은 발급하거나 저장하지 않는다.
- AccessToken의 사용자 식별 claim에는 `userId`만 저장한다. 만료 검증을 위한 표준 메타데이터는 허용한다.
- 인증 필터가 검증한 `userId`는 Spring Security의 인증 principal로 제공한다.
- 토큰 서명 키와 데이터베이스 접속 정보는 설정으로 주입하고 코드에 운영 값을 하드코딩하지 않는다.
