# 변경 리뷰

사용자가 지정한 파일, 커밋 또는 비교 기준을 따른다. 지정이 없으면 작업 트리의 변경을 검토한다. 변경이 없으면 현재 작업에서 만든 커밋을 검토하고, 그 범위도 확인할 수 없으면 비교 기준을 질문한다.

`verifier`에 다음 내용을 전달하고 리뷰를 위임한다.

- 요구사항과 변경 범위, 비교 기준 및 관련 호출부
- 실행한 검증과 결과, 아직 확인하지 못한 사항
- Java 변경이 있으면 프로젝트 루트 `GoogleStyle.xml`의 경로와 해당 설정을 기준으로 포맷도 검토하라는 지시
- 관련 테스트 실행은 허용하되 소스·테스트·설정 수정과 커밋은 하지 말라는 지시

주 에이전트는 결과를 기다린 뒤 지적을 실제 코드와 요구사항에 대조한다. 확인된 문제는 중요도, 파일·줄 번호, 발생 조건과 영향으로 보고한다. 문제가 없다면 그 사실과 남은 검증 한계를 전달한다.

리뷰만 요청받았다면 코드를 수정하지 않는다. 수정까지 허용되었다면 주 에이전트가 직접 수정하거나 `implementer`에 담당 파일을 지정해 위임하고, 수정한 동작을 다시 검증한다. 검증과 커밋은 프로젝트 AGENTS.md를 따른다.

에이전트를 사용할 수 없다면 제한을 알리고 주 에이전트가 직접 검토한다. 이 경우 독립된 에이전트 리뷰를 수행했다고 보고하지 않는다.
