# 변경 리뷰

공통 기준은 프로젝트 `AGENTS.md`를 따른다.
사용자가 지정한 파일·커밋·비교 기준을 검토한다. 지정이 없으면 작업 트리, 현재 작업의 커밋 순으로 범위를 찾고 불명확하면 확인한다.

`verifier`에 요구사항, 변경 범위, 비교 기준, 관련 호출부와 기존 검증 결과를 전달한다.
주 에이전트는 지적을 실제 코드와 대조하고 확인된 문제와 검증 한계를 보고한다.
리뷰만 요청받았다면 수정하지 않는다. 수정이 허용되면 직접 수정하거나 `implementer`에 위임한 뒤 재검증한다.
에이전트를 사용할 수 없으면 직접 검토하고 독립 검토를 수행하지 못한 사실을 보고한다.
