# 변경 리뷰

## 범위 확인

사용자가 지정한 파일, 커밋 또는 비교 기준을 따른다. 별도 지정이 없으면 현재 작업 트리의 변경을 검토한다. 작업 트리에 변경이 없으면 현재 작업에서 만든 커밋을 검토하고, 그 범위도 확인할 수 없으면 비교 기준을 질문한다.
프로젝트 AGENTS.md와 변경 내용을 읽고, 요구사항 및 관련 호출부를 확인한다. 리뷰 요청만으로 코드를 수정하지 않는다.

## 리뷰 위임

`backend_reviewer` 서브에이전트에 리뷰를 위임한다. 다음 내용을 전달한다.

- 요구사항과 검토할 변경 범위 및 비교 기준
- 변경한 파일과 확인이 필요한 관련 호출부
- 실행한 검증과 그 결과, 아직 확인하지 못한 사항
- 파일 수정과 커밋 없이 문제의 중요도, 파일·줄 번호, 발생 조건, 영향을 보고하라는 지시

주 에이전트는 결과를 기다린 뒤 각 지적을 실제 코드와 요구사항에 대조한다. 에이전트를 사용할 수 없다면 그 제한을 알리고 주 에이전트가 직접 검토한다. 이 경우 독립된 리뷰를 수행했다고 보고하지 않는다.

## 결과와 후속 처리

리뷰만 요청받았다면 확인된 문제와 남은 불확실성을 보고한다. 문제를 찾지 못한 경우에도 실행하지 못한 검증이 있으면 명시한다.

구현이나 수정까지 허용된 작업이라면 주 에이전트가 확인된 문제를 요청 범위 안에서 수정하고, 수정한 동작에 관련된 테스트를 실행한다. 검증과 커밋은 프로젝트 AGENTS.md를 따른다. 리뷰어가 수정하거나 커밋하게 하지 않는다.
